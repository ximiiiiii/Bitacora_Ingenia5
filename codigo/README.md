# Código

Esta carpeta contendrá el código del prototipo Hub Conecta. La propuesta y su arquitectura preliminar están definidas. Se incorporarán las versiones, instrucciones de instalación y evidencias técnicas conforme avance el desarrollo.

## Diseño técnico previsto

- Backend en Python con FastAPI.
- Interfaz en HTML, CSS y JavaScript, adaptable a computadores, tablets y celulares compatibles.
- Base SQLite con SQLAlchemy para la etapa de prueba controlada.
- Generación de QR único por reserva y lectura por el personal mediante la cámara del dispositivo.
- Panel administrativo y exportación de registros autorizados a Excel (.xlsx).

Estas decisiones describen el desarrollo previsto; no acreditan código implementado ni pruebas ejecutadas.

## Contenido que se incorporará

Código fuente, dependencias, instrucciones de ejecución, datos ficticios y casos de prueba. No se publicarán credenciales, tokens QR válidos de usuarios reales ni registros personales.
